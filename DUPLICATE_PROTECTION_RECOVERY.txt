Deploy this entire ZIP to the existing familyguard-global-survey Pages project using the same deployment method already used for this project. Wait for Production to finish deploying before running the reconciliation step.

LIMITATIONS
The server rule is one response per internet connection. Shared Wi-Fi may affect multiple people; VPNs or network changes can produce different IPs. Browser local storage provides additional same-browser protection. Keep DUPLICATE_HASH_SECRET stable to preserve historical matching.
